What lives where?
W
Learned weights
Bundled with the static page and server code. Reused without updates during inference.
C
Context and KV cache
Created for a model run. The server uses a separate model instance for each request.
D
Database and long-term memory
This example has neither. A production app can retrieve stored records into the request context.
G
GPU and model service
This 48k-parameter model runs on CPU. Larger models typically use a dedicated inference service; this Worker can become its API gateway.
