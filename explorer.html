A three-minute tour.

Use the pipeline to tell the story, then open memory and sampling to make the key ideas tangible.

01 / INPUT

The app constructs the context.

Start with the briefing scenario. Point out instructions, history, selected saved facts, the user message, and available tool descriptions. The model receives the assembled input.

02 / COMPUTATION

Tokens become vectors.

Step through all five blocks. Each block uses causal attention and a feed-forward network. Click a block to inspect actual weights from this tiny, untrained transformer. Layer numbers are not separate cognitive skills.

03 / ACTION

The app executes tool calls.

Watch the model request fan out to the fictional mail and file tools. Their results return as context. Tools and subagents are application capabilities, not mandatory neural layers.

04 / OUTPUT

Generation repeats.

During decoding, each new unit is run through the blocks and added to the cache. The response is scripted for clarity; an actual trained model predicts token scores from its final hidden vector.

05 / MEMORY

Remove information and compare.

Choose “Remember a conversation.” Disable history and rerun: the example no longer knows the dog’s name. In Memory map, end a session and see which kinds of state can persist.

SCOPE / WHAT IS SIMULATED

A common pattern, at teaching scale.

  • Real math: embeddings, causal attention, residuals, layer normalization, MLP, KV caching, softmax sampling.
  • Scripted: scenario routing, tool results, response text.
  • Simplified: word/punctuation tokenizer, five blocks, one attention head.
  • Frontier models vary; exact private architectures and reasoning are not exposed here.
